# تحديث بيانات النظام القديم

النسخة الحالية (`traveliun-legacy.sql`) مأخوذة في **٢٠ يوليو ٢٠٢٦**. كل فندق أو
خدمة أو مدينة أُضيفت في النظام القديم بعد ذلك التاريخ ليست عندنا.

الاستيراد **يُعاد تشغيله بلا تكرار** — كل صفّ محروس بـ`legacy_id_map`، فنسخة
جديدة تُضيف الناقص فقط ولا تلمس ما استُورد.

---

## ١. صدّر النسخة من cPanel

1. cPanel ← **phpMyAdmin**
2. من العمود الأيمن اختر **`tourhawl_traveliun_app`**
   (هذه قاعدة `app.traveliun.com`. والقاعدة الأخرى `tourhawl_systraveliun`
   هي النظام الأقدم، ولم نعد نقرأ منها.)
3. تبويب **Export** ← Export method: **Quick** ← Format: **SQL** ← **Go**
4. ضع الملف هنا، في مجلّد `data-import/`

> لا يُرفع أي ملف من هذا المجلّد إلى GitHub. المستودع **عام**، والنسخة تحوي
> أسماء عملاء وأرقام جوالات **وأسعار الشراء والهوامش**.

---

## ٢. شغّل الاستيراد

ثلاثة أوامر:

```bash
node scripts/legacy-extract-reference.mjs data-import/<اسم-الملف>.sql
```

يستخرج الجداول المرجعية وحدها إلى `data-import/extracted/` ويطبع عدد صفوف كل
جدول. **لا يقرأ العملاء ولا العروض ولا الموظفين.**

```bash
node scripts/legacy-build-reference-sql.mjs
```

يبني `scripts/legacy-import-app-reference.sql` — ملفٌّ يمكن قراءته ومراجعته
قبل أن يمسّ قاعدة البيانات.

```bash
node scripts/db-apply.mjs scripts/legacy-import-app-reference.sql
```

## ٤. ثلاثة قرارات مكتوبة في المولّد، تُراجَع إن تغيّر النظام القديم

**خريطة الأسماء البديلة** (`COUNTRY_ALIAS`). ثماني دول في النظام القديم هي
دولنا نفسها باسم آخر: «بريطانيا» = المملكة المتحدة · «سلطنة عمان» = عُمان ·
«جمهورية التشيك» = التشيك · «الامارات» = الإمارات العربية المتحدة · «البوسنه» =
البوسنة والهرسك · «سيرلانكا» = سريلانكا · «الولايات المتحدة الامريكية» =
الولايات المتحدة. بلا هذه الخريطة يُنشئ الاستيراد ثماني دول مكرّرة ويشتّت
فنادق كلّ واحدة بين صفّين لا تجمعهما شاشة.

**«اوربا» ليست دولة** (`COUNTRY_SKIP`) — كانت تُستخدم للبرامج متعدّدة الدول،
وإدخالها يضع قارّة في قائمة الدول.

**سعة المركبة** تُقرأ من الاسم حين يذكرها («باص ١٤ مقعد»)، وإلّا فمن أكثر
إجابة تكراراً في `cars` — لأن النظام القديم يخزّنها لكل دولة على حدة ويناقض
نفسه: «سيارة صغيرة» ٣ ركاب في صفّ و٢ في آخر للدولة نفسها.

## ٥. أمور في بياناتهم نُقلت كما هي، ولم تُصحَّح

- «باص كبير / Big bus» مسجَّل بـ**٨ ركاب**.
- «باص ٤٩ مقعد» إنجليزيّته `48 seat bus`.
- إندونيسيا فيها «استقبال بالورد» **مرّتين** بسعرين مختلفين.
- أربعة رموز طيران ليست رموزاً: «سيارة» · «AIR LIBERTÉ» · «12GO» — تُسقَط،
  و«AA» المسبوق بكسرات يُنظَّف ويُقبل.
- «الإمارات» نهاية أسبوعها في نظامهم الجمعة والسبت، وهو ما تغيّر فعليّاً إلى
  السبت والأحد سنة ٢٠٢٢. نُقل كما هو لأنه جوابهم؛ صحّحه من الشاشة إن أردت.
