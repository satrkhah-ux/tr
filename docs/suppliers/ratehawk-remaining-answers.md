### ملاحظتان تستحقّان الانتباه

**الصف ٤٤ — لا تعلّم «Through API».** تعليمها يعني أنك تعيد بيع أسعارهم عبر
API لطرف ثالث، وهو بند تعاقدي مختلف تماماً بأسعار وشروط أخرى. نحن نبيع من
موقعنا فقط.

**الصف ٢٥ — التأشيرات ليست في قائمتهم.** إن أردت ذكرها فتحت `O` Other، لكنها
لا تخصّ تكاملهم فالأفضل تركها.
