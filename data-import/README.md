# data-import — نقل بيانات النظام القديم

مجلد استقبال نسخ قواعد البيانات القادمة من النظام السياحي السابق (سيرفر cPanel)
قبل ترحيلها إلى قاعدة بياناتنا الحالية (PostgreSQL / Supabase).

## ⚠️ لا يُرفع أي ملف من هنا إلى GitHub

المستودع **عام**، والنسخة تحتوي أسماء عملاء وأرقام جوالات وأسعار حقيقية.
ملف `.gitignore` في هذا المجلد يمنع رفع كل شيء عدا نفسه وهذا الملف — لا تعطّله.

## كيف تُصدّر النسخة من cPanel

1. cPanel ← **phpMyAdmin**
2. اختر قاعدة بيانات النظام القديم من العمود الأيمن
3. تبويب **Export**
4. Export method: **Quick** — Format: **SQL** ← ثم **Go**
5. سيتنزّل ملف `.sql` (أو `.sql.gz`)

ضع الملف داخل هذا المجلد، ثم افحصه قبل أي شيء:

```bash
node scripts/inspect-sql-dump.mjs data-import/<اسم-الملف>.sql
```

يطبع الجداول وأعمدتها وعدد صفوف كل جدول — ومنه تُبنى خطة المطابقة على جداولنا
(`customers` / `employees` / `countries` / `cities` / `hotels` / `offers` …).

## لماذا لا يكفي «نسخ» الملف كما هو

النظام القديم **MySQL** ونظامنا **PostgreSQL**: الأنواع والدوال ومفاتيح الهوية
تختلف، وجداولنا ليست بنفس الأسماء ولا بنفس الأعمدة. فالنقل مطابقة (mapping)
مكتوبة كـ migration + سكربت استيراد، وليس استعادة نسخة احتياطية.
